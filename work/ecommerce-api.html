02 / Overview

The backend of a shop, built to be predictable.

REST APIs for product, cart and order management with input validation and clean JSON responses. Authentication and role-based access control use Django's built-in auth system, on top of a normalised MySQL schema with ORM logic for stock updates and order totals.

E-Commerce API / how the parts connect

03 / The problem

Money and stock leave no room for "usually correct".

An e-commerce backend has to keep stock, carts and orders consistent, reject bad input, and make sure customers cannot do what only staff should. Those rules belong in the API and the schema, not in each screen.
