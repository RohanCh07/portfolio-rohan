01 / Overview

The back office behind the product.

During my AI Research internship at Coding Jr I worked as a Software Development Engineer on the company's internal admin panel. I designed its backend logic and implemented core features together with the team.

02 / The problem

Internal teams need one dependable place to manage the platform.

An admin panel is used every day by the people running the business, so its backend has to be predictable: clear endpoints, consistent rules, and features the team can build on.

  • Daily operational work for internal teams
  • Rules that must behave the same every time
  • A base the team can keep extending

03 / How it works

A backend designed for the panel the team uses every day.

  1. 01

    Model

    Design the backend logic behind each panel feature.

  2. 02

    Expose

    Serve it to the panel through REST APIs.

  3. 03

    Build

    Implement the core features with the team.

  4. 04

    Iterate

    Extend and refine as the team's needs grow.

04 / Key decisions

The choices that shaped it.

01

Question

How should the panel talk to the backend?

Choice

Through REST APIs.

Effect

The panel and future tools can share the same backend logic.

02

Question

Where do the rules live?

Choice

In the backend, not the interface.

Effect

Behaviour stays consistent whichever screen triggers it.
