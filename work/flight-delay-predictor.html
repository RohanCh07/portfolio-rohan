02 / Overview

Will this flight leave on time? A forecast from live data.

A real-time prediction system that forecasts flight delays across major Indian airports. A data pipeline collects live flight and weather data from external APIs, a machine-learning model predicts delays, and an interactive Streamlit dashboard shows live flight status next to the forecasts.

  2. Prepare

Flight Delay Predictor / how the parts connect

03 / The problem

Delays depend on things that change by the minute.

Weather, traffic and schedules all move during the day, so a static timetable says little about whether a flight will actually leave on time. A useful forecast needs live inputs and a model that combines them.

    Conditions that change through the day
