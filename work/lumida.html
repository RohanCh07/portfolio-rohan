01 / Overview

Point it at a database. Read the findings over coffee.

Lumida connects read-only to an existing database and builds a picture of it on its own: which tables really relate to each other, what normal looks like for each column, and where the data has drifted. Every finding arrives with the evidence behind it and a plain-language explanation, so the person reading it does not need to know the schema by heart.

02 / The problem

Bad data rarely breaks loudly. It hides in the joins nobody wrote down.

Most production databases carry relationships that were never declared as foreign keys, and problems that only show up when a report looks wrong weeks later. Finding them by hand means reading the schema, guessing the joins and writing one-off queries — work that is slow and never finished.

  • Undeclared relationships between tables
  • Orphaned and inconsistent rows that pass every constraint
  • Findings that need explaining to people who did not build the schema

03 / How it works

Five steps, one direction: from the raw tables to a finding someone can act on.

  1. 01

    Connect

    Read-only connection to the database. Nothing is written back.

  2. 02

    Map

    Infer the relationships between tables that were never declared.

  3. 03

    Detect

    Profile each table and flag rows and values that break the pattern.

  4. 04

    Explain

    An LLM turns each finding and its evidence into plain language.

  5. 05

    Learn

    People confirm or dismiss findings, and Lumida learns from it.

04 / Key decisions

The choices that shaped it.

01

Question

Should it be allowed to fix what it finds?

Choice

Read-only, always.

Effect

It can be pointed at production without risk, which is where the real problems live.

02

Question

Who decides that something is a problem?

Choice

The engine detects; the LLM only explains.

Effect

Findings stay reproducible and evidence-based, and the language model never invents an issue.

03

Question

How does it get better without retraining?

Choice

A confirm / dismiss loop on every finding.

Effect

Each review tunes what Lumida treats as normal for that database.
