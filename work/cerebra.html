01 / Overview

Ask for what you need. Get a request that is ready to submit.

Cerebra is a chatbot used inside Moglix to create purchase requests (PRs) and requests for quotation (RFQs) in Credlex. Instead of filling a long form field by field, people describe what they need in their own words and Cerebra drafts the request for them.

02 / The problem

Raising a request meant a long form, even for something simple.

Purchase requests and RFQs carry many structured fields. Filling them in is slow and easy to get wrong, and the information usually already exists in how the person would describe the need out loud.

  • Many fields for one simple need
  • The same details typed again for every request
  • A slow path from "we need this" to a request in the system

03 / How it works

From a sentence to a structured request, through the same APIs the app uses.

  1. 01

    Ask

    The user describes the need in plain language.

  2. 02

    Understand

    The LLM extracts the item, quantity, dates and other fields.

  3. 03

    Draft

    Cerebra fills a PR or RFQ draft and shows it back.

  4. 04

    Confirm

    The user checks the draft before anything is created.

  5. 05

    Create

    The request is created in Credlex through its REST APIs.

04 / Key decisions

The choices that shaped it.

01

Question

Should the assistant create requests on its own?

Choice

Draft first, create only after the user confirms.

Effect

People stay in control of what is submitted, and mistakes are caught before they reach the system.

02

Question

How should it talk to Credlex?

Choice

Through Credlex's existing REST APIs.

Effect

Requests follow the same rules and validation as ones made in the app.
