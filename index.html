Case notes

Lumida connects read-only to any database and maps it: the relationships nobody documented, what "normal" looks like for each table, and where the data has drifted. Every finding comes with evidence and a plain-language explanation from an LLM, and it learns each time someone marks a finding as real or not.

On a test database with planted issues it found all 15 hidden relationships and all 13 problems, with zero false alarms.

Case notes

Distiller is an OpenAI-compatible gateway, so a team adopts it by changing one line. It logs the company's repeated LLM calls, fine-tunes small open models with LoRA to copy the big model on those tasks, tests them in shadow mode, then sends the requests it's confident about to the cheap model and falls back to the big one when it isn't.

Status: the gateway and CLI work. Training and routing are in development.
